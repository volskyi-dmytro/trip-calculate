# Trip Calculate seasonal backgrounds

Complete coordinated set, created 28 September 2026.

- Eight hero masters: winter, spring, summer and autumn, each in desktop (2172 × 724) and mobile (1024 × 1536) formats.
- Six newly generated winter/spring/summer variants use the previously approved hero as their composition/style reference.
- The approved original is copied unchanged as `autumn-desktop.png` and `autumn-mobile.png`.
- `planner-empty.png` is the original transparent supporting illustration, included for convenience.
- All artwork was produced with the built-in image generation tool. New generation prompts are in `generation-prompts.json`; the original prompts are in `original-generation-prompts.json`.
- `manifest.json` contains dimensions, sizes and checksums of all nine PNG files.

Open `gallery.html` to compare the artwork. Give your coding assistant `INTEGRATION-PROMPT.md` along with this entire folder. That prompt is ready to paste and covers source inspection, responsive integration, automatic season selection, optimized WebP exports, derived ambient backgrounds and validation.

These are original PNG masters. Optimized WebP/ambient derivatives are deliberately part of the coding assistant's integration task, so they can be generated with the project's own tooling. No production application files were changed or deployed.
